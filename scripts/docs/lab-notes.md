# Lab Notes

## Lab Title

Linux Fundamentals and Bash File Automation

## Purpose

The purpose of this lab is to develop foundational skills in Linux command-line usage and Bash scripting.

## Core Concepts

- Filesystem navigation
- Directory management
- File management
- File copying and movement
- Linux executable permissions
- Bash scripting
- Basic automation
- Result verification

## Practical Verification

The lab was designed to verify that the learner can perform basic filesystem operations manually and automate a simple file-creation workflow using Bash.
